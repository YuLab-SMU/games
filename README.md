# 🎯 24点大冒险

一个面向小学生的 24 点数学益智游戏，纯单文件 HTML，打开即玩。

## 玩法

1. 4 张数字卡片（1-10），通过 + − × ÷ 凑出 24
2. 逐步配对：选数字 → 选运算符 → 选数字 → 合并 → 重复到只剩 1 张
3. 中间结果必须为整数，否则无法合并

## 功能

- **三套主题**：水果乐园 / 太空冒险 / 动物森林
- **普通模式**：计时答题，3 步完成得 3 星，否则 2 星
- **生存挑战**：2 分钟倒计时，答对重置计时器，速度越快奖励越多
- **连击系统**：连续答对星星翻倍（最高 5 倍），屏幕 COMBO 大字特效
- **本地排行榜**：Top 5 按星星排序，数据存 localStorage
- **音效 + 动画**：Web Audio 音效、撒花粒子、卡片动画
- **响应式**：自适应桌面 / 平板 / 手机

## 运行

```
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

或直接双击 `index.html`。
