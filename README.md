大鱼吃小鱼风格进化游戏。控制"节奏盒子"在地图上移动，吃同级/低级的进化，躲开高级的保命。

- 五套场景（太空/深海/森林/赛博/糖果）
- 25 个 AI 角色同屏 / 追逃行为 / 连击特效 / 本地排行榜
- 键盘方向键/WASD 移动，移动端自动启用虚拟摇杆
