## 📦 召唤进化

大鱼吃小鱼风格进化游戏。内置**节奏盒子**（Sprunki）与**山海经**（脑残）双主题，控制角色吃同级/低级的进化，躲开高级的保命。

> 节奏盒子进化链：瑞迪 → 佳诺德 → 布莱克 → 格雷 → 快乐机器人 → 小天 → 奥伦 → 太阳先生 → 大树先生 → 杰文 → …… → **平基** 👑
> 山海经进化链：…… → **茶壶人** ☕

- 双主题皮肤（经典/焕新）/ 五套场景（太空/深海/森林/赛博/糖果）
- 25 个 AI 角色同屏 / 追逃行为 / 跟随·狩猎·护卫三模式 / 连击特效 / 本地排行榜
- 键盘方向键/WASD 移动，移动端自动启用虚拟摇杆
- [summon-evolution/index.html](summon-evolution/index.html)

## 🔢 数独

经典 9×9 数字谜题。回溯生成保证唯一解，三档难度（简单/中等/困难）。

- 笔记模式（铅笔标记候选）/ 撤销 / 提示 / 冲突高亮
- 同行·同列·同宫高亮 + 相同数字高亮
- 数字剩余计数 / 计时 / 错误统计
- 键盘（方向键 + 数字 1-9 + N 笔记 + Ctrl+Z 撤销）与触屏双支持
- [sudoku/index.html](sudoku/index.html)
